# 09 — Acceptance Criteria & Definition of Done

Чеклист приёмки. Генератор после завершения работ **обязан** пройти каждый пункт. Пункт провален → доработать код, не оправдываться.

---

## 9.1 Build & Run

- [ ] `npm install` завершается без ошибок
- [ ] `npm start` / `ng serve` поднимает приложение
- [ ] Консоль браузера без ошибок runtime при старте
- [ ] Нет красных ошибок Angular (NG0xxx) в консоли
- [ ] Zoneless: приложение реагирует на play/pause и selection без Zone.js hacks
- [ ] В зависимостях нет chart.js / three / tailwindcss / ngrx

---

## 9.2 Биология / симуляция

- [ ] На старте есть растения, зайцы и волки (численность из appendix A)
- [ ] Жертвы движутся к растениям и увеличивают энергию при поедании
- [ ] Растения удаляются/помечаются мёртвыми после поедания; есть regrowth в пределах MAX_PLANTS
- [ ] При появлении хищника в радиусе зрения жертва переходит в panic и убегает
- [ ] Хищники преследуют жертв и получают энергию при успешной охоте; жертва умирает
- [ ] Энергия падает от метаболизма; при 0 агент умирает
- [ ] При низкой энергии скорость агента снижена
- [ ] Размножение: два готовых агента одного вида создают потомка
- [ ] Потомок имеет generation = max(parents)+1
- [ ] ДНК потомка получается crossover + mutate; гены в допустимых диапазонах
- [ ] Spatial hash используется для nearest queries (код присутствует и вызывается)
- [ ] Лимиты MAX_PREY / MAX_PREDATORS / MAX_PLANTS / MAX_TOTAL_AGENTS соблюдаются
